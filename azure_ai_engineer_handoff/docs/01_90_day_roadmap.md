# 90-Day AI Engineer Roadmap

## The Core Philosophy

The primary directive is shifting from "notebook data science" to "production
software engineering."

*   **Certifications:** Foundational certs are irrelevant. Focus only on
    professional Azure certs (like Azure AI Engineer Associate) if partner status
    requires it or for mastering MLOps infrastructure.
*   **Success Metric:** Shipping robust, scalable models that integrate with the
    core product, rather than endlessly chasing marginal accuracy gains.

## Timeline

Blocks run **last-first** per house style — the final block leads so the shape of
"done" is visible before the first step. Day numbers are fixed and never
renumbered: execution order is `1–30 → 31–60 → 61–90`, read off the numbers, not
off the page order.

### Days 61-90 — Scale & Ownership

1.  Take ownership of a pipeline.
2.  Implement monitoring (latency, costs, drift).
3.  Optimize performance.
4.  Document architectural decisions.

### Days 31-60 — First Measurable Win

1.  Focus on a narrow, quantifiable problem (e.g., optimizing RAG retrieval speed).
2.  Write production-ready APIs to connect ML models to the core backend.

### Days 1-30 — Context & Infrastructure

1.  Master data pipelines.
2.  Understand the Azure deployment stack.
3.  Push a small bug fix through the full CI/CD pipeline.
