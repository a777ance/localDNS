# M04 · tools/check-superfleet.py

## Defects

- tools/check-superfleet.py line 102-112: an unknown or misspelled flag silently runs the plan check. `if args[:1] == ["--review"]` misses a typo such as "--revew", so control falls through to `check_plan` on line 112, which prints "ok" and exits 0. A review request is dropped with a clean result.
- tools/check-superfleet.py line 116 (and line 4): the plan check never asserts the scenario count the docstring states ("The plan describes ten scenarios"). An empty or truncated `scenarios` list gives zero problems and prints "ok   superfleet plan: 0 scenarios, 0 lanes", so a gate that should fail passes.
- tools/check-superfleet.py line 50-52: `re.search(r"tools/matrix\.py (\w+\.\w+)", first)` stops at the first word character run, so "act.ship-now" is read as "act.ship". If "act.ship" exists in matrix.py, the invalid method name passes. The `\w+` capture also drops any suffix after the first hyphen.
- tools/check-superfleet.py line 51: `if m and f'"{m.group(1)}"' not in matrix` tests only that the quoted name appears somewhere in the text of tools/matrix.py. A name that appears in a comment or docstring but is not implemented passes, although the docstring on line 13 says the check is that the method "does not exist" (implements).
- tools/check-superfleet.py line 86: `outside = [f for f in changed if not f.startswith(lane["write_area"])]` is a bare prefix test with no slash boundary. A write area of "docs/ai-cto/fleet/x" lets a file at "docs/ai-cto/fleet/x2/file" pass as inside it. The review also reads `lane["write_area"]` directly, so it never runs the trailing-slash and HOME checks that check_plan applies on line 65. The review can therefore pass a lane whose plan entry the plan check would fail.
- tools/check-superfleet.py line 16-17 and line 79: the docstring says the review compares the branch "with the branch `leader`", but the code runs `git diff --name-only origin/leader...{branch}` on line 79. The two readings differ, because a local `leader` and `origin/leader` can point at different commits.

## Notes

The check reads .claude/superfleet.json by path (line 28) and the commit gate is said to run it (line 6). Neither the plan file nor the gate script was opened in this milestone, so the claim that the gate runs this check, and that the plan holds ten scenarios, are unverified here.

The --list path (lines 96-101) and the review path (line 76) index keys such as s["id"], s['title'] and s['look_first'] without a default. A malformed plan therefore crashes with a traceback and exit 1 instead of a FAIL line. That is loud rather than silent, so it is not counted as a defect.

The look-first check (lines 49-57) takes only the first "tools/matrix.py" reference, because re.search returns one match. A look-first step that names a second method is not checked. This is a coverage limit, not a silent failure of the stated check, so it is not counted as a defect.

The review on line 83-85 rejects an empty write area, and the comment there explains why. That guard is correct and is not a defect.
