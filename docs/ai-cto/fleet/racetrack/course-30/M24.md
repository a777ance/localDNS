# M24 · .claude/hooks/precompact.py

## Defects

- `.claude/hooks/precompact.py:19` — `timeout=4` raises subprocess.TimeoutExpired when git is slow, and the `except` at lines 48-49 turns that into empty output. The compaction then gets no keep-list at all, and nothing says so. Fix: give each `git` call its own try that returns an empty string and records the miss in the output.
- `.claude/hooks/precompact.py:31` — the lease regex `` `(start: [^`]*expiry: [^`]*)` `` requires `start:` before `expiry:` inside one backtick span. A handoff that writes the fields in another order, or with other wording, matches nothing. Line 38 then prints `none recorded`, which the compaction summary reads as "there is no lease," and the summary may drop a real one. Fix: match each field separately, and print "not found in handoff.md" rather than "none recorded".
- `.claude/hooks/precompact.py:32` — the queue regex `^- \*\*(S?Q-\d{3}) · (.*?)\*\*.*$` requires the exact `·` separator and exactly three digits. A queue line that differs in any of those does not match. Line 40 then prints `none left unblocked`, which reads as an empty queue when the regex simply failed. Fix: fall back to "queue format not recognized" when no line matches.
- `.claude/hooks/precompact.py:33` — `re.search("BLOCKED|DONE|SKIPPED", m.group(0))` is a case-sensitive substring test with no word boundaries, run on the whole line. An item whose text contains `ABANDONED` or `UNDONE` is skipped as if it were finished, and the next open item is named in its place. Fix: match the status as a whole word in the status field only, for example `\b(BLOCKED|DONE|SKIPPED)\b` against the bold tag.
- `.claude/hooks/precompact.py:34` — the decisions regex `^- \*\*(DEC-\d{3}) · .*? · OPEN\*\*` expects a list bullet with the id in bold and `· OPEN**` at the end of the bold span. The decision tile format in CLAUDE.md is `**DECISION · DEC-NNN · <question>**`, which does not match. An open decision in that form gives `Open founder decisions: none` at line 39, and the compaction summary then drops it. This file cannot confirm the blocked.md format; verify by grepping `docs/ai-cto/blocked.md` for the `OPEN` marker and check the regex matches a real line.
- `.claude/hooks/precompact.py:45` — `', '.join(l.split()[-1] for l in dirty.splitlines())` keeps only the last whitespace-separated token of each `git status --short` line. A path with a space is cut to its last word, and a rename `R  old -> new` shows only `new`. The count on line 45 is still right, but the names are not. Fix: take `line[3:]`, and for a rename take the part after ` -> `.
- `.claude/hooks/precompact.py:47` — `print(out[:1190])` cuts the summary at 1190 characters with no marker. The uncommitted-work line (lines 44-46) is appended last, so it is the first thing lost when the earlier lines run long. Line 41 alone can run to 110 characters and line 45 to 300, so a dirty tree can lose its warning silently. Fix: build the mandatory lines first and truncate the optional text, or cut each field to a fixed budget.
- `.claude/hooks/precompact.py:4` — the docstring says the stdout "is passed to the compaction as instructions." This is a claim about the PreCompact hook contract. It is not verified in this file, and if the harness only shows it to the user, the whole file's purpose is lost. Verify against the hooks documentation before relying on it.

## Notes

Line 30 falls back from `docs/ai-cto/superqueue.md` to `handoff.md` when the superqueue is empty, not only when it is missing. That is probably intended, since an empty superqueue is no queue, but it is a silent switch of source. Note it in the docstring if it is meant.

Line 19 runs `git` with `cwd=ROOT`, so the repository is the one the hook sits in, and line 41's `git log -1` gives a blank string on a repository with no commits. The summary then prints an empty `Last shipped commit:` line. That is acceptable, but it is not an error message.

Line 32's `item` is the first match that is not blocked, done, or skipped, so the summary names one queue item. If the founder needs more than one, the hook does not provide them.
