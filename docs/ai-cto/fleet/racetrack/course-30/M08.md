# M08 · docs/ai-cto/checkpoint.md

## Defects

- docs/ai-cto/checkpoint.md line 33 says "seven reply rules enforced by the Stop hook", but line 43 says "Reply rules, now eleven, all in .claude/hooks/decide-act.py", and CLAUDE.md states the Stop hook enforces eleven rules. A reader following line 33 would believe four rules are unenforced or missing.
- docs/ai-cto/checkpoint.md line 72 lists DEC-020 under "Open founder decisions", but the live block at line 18 lists only "DEC-019, DEC-018, DEC-005", and docs/ai-cto/blocked.md line 48 gives DEC-020 the status "GO · executed in part", not OPEN. The hand-written prose list and the generated live list disagree on whether DEC-020 is open, so a reader cannot tell whether the founder still owes a decision on it.
- docs/ai-cto/checkpoint.md line 78 says "Start at its first open item in the loop's lane." The phrase "the loop's lane" is not defined in this file, so a reader cannot tell which lane to start in.

## Notes

The live block (lines 15 to 26) is rewritten by orient.checkpoint, and the markers it uses, live:start and live:end, match what tools/matrix.py expects. The two commands on line 5 (orient.probe and decide.open) and the one on line 13 (orient.checkpoint) exist in tools/matrix.py. The referenced files on lines 30 to 31, 50 to 53, 56, 79 and 83 all exist in the repo. The superqueue's first item is SQ-001, as line 52 says. I did not count the nine gates on line 33 or the ten panels on line 56, so those figures are unverified.

Line 9 says work lands on leader, while line 16 names a session branch, claude/serene-tesla-yvl22m. Read with docs/ai-cto/branches.md, these agree (each session cuts its branch from leader), but the file does not say so, so a reader may take the branch line as the place work lands.

Lines 36 to 37 tell the reader to "ignore any older text that cites" the two lease names, without saying where that older text is. This is an instruction a check cannot test.

Lines 63 to 65 say a session may not launch parallel subagents. This is a standing limit on sessions, not a check that fails, but it bears on any run that is itself a subagent.

Line 88 reads "its first version was seen working" without saying which version is meant. It is probably the setup script, but the sentence does not name it.

Line 3 to 5 send the reader to orient.probe and decide.open, while CLAUDE.md says Orient reads initiatives.md, debt.md and blocked.md from disk. Both can be followed at once, so this is not a defect.
