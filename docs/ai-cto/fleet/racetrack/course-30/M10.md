# M10: tools/check-docs.py

Source: `/home/user/localDNS/tools/check-docs.py` (494 lines).

Reading of the question: "silently fail" is taken as the check passing or skipping a case it should flag.

## Defects

1. **Dot-directories are never scanned (line 451-453).** `glob.glob("**/*.md", recursive=True)`. Python's `**` does not descend into hidden directories, so `.claude/**/*.md` (the command, agent and skill docs that CLAUDE.md §G cites) is never checked. The docstring (line 4) says "every `*.md` file in the repo". The filter `if not p.startswith(".git" + os.sep)` on line 453 is therefore dead code.

2. **Inline repo paths under `.claude/` are never checked (line 45-48 and 126).** `REPO_TOP` lists only `01-core-network`, `02-performance`, `03-monitoring`, `04-user-services`, `vault`, `tools`, `docs`. `return first in REPO_TOP` (line 126) returns False for `.claude/hooks/gate.sh`, `.github/...` and similar, so a dangling `.claude/` path in backticks passes.

3. **Glob tokens pass when only the parent exists (line 114-116).** `return any(os.path.isdir(os.path.join(b, parent)) for b in bases)`. A glob that matches nothing still passes. For a bare token such as `*.md`, `parent` is `""`, `os.path.join(b, "")` is the base directory itself, and the check is always true.

4. **Link fragments are never validated against the target file (line 177).** `filepart = target.split("#", 1)[0]`. The fragment is discarded, so `a markdown link to file.md with a fragment` passes whenever `file.md` exists.

5. **Fenced blocks are recognised only for backticks (line 87 and 101).** `if re.match(r"^\s*```", ln):`. A `~~~` fence is not recognised, so a `# heading` inside a `~~~` block becomes a real anchor (line 92), and example links or paths inside it are treated as live (lines 169 and 186). Read two ways: the same text is code to one renderer and prose to this check.

6. **Anchor de-duplication does not record generated names (line 76-80).** `if s in seen:` then `s = f"{s}-{seen[s]}"`. The generated `foo-1` is never added to `seen`, so a later heading that slugifies to `foo-1` is not de-duplicated and the anchor set is wrong for that heading. A broken anchor can resolve silently.

7. **An empty link target crashes the run (line 170).** `target = raw.strip().split(None, 1)[0]`. For `[x]()`, `raw` is empty, `split` returns `[]`, and `[0]` raises IndexError. The crash is loud, but it aborts the loop for every later file, so the rest of the docs go unchecked.

8. **Glyph rows can be paired across rows (line 330-332).** `GLYPH_HTML = re.compile(r'<td class="glyph">(.*?)</td>.*?<td class="arch">(.*?)</td>', re.S)`. If a row has no `arch` cell, the `.*?` runs into the next row and one row's glyph is paired with the next row's archetype. A glyph can be compared against the wrong role.

9. **Two entity decoders for the same text (line 355 vs line 238).** Line 355: `g = re.sub(r"<[^>]+>", "", g).replace("&nbsp;", "").replace("&amp;", "&")` decodes two entities by hand. Line 238 uses `html.unescape(raw)`. A page glyph written as `&#96;` or `&lt;` keeps its entity, so the key differs from the canonical glyph and is reported as "absent" rather than matched.

10. **Separator detection depends on exact spellings (line 387).** `if not glyph or not archetype or archetype in ("archetype", "---", ":--"):`. A separator row written `|:--:|` yields a non-empty glyph and archetype `":--:"`, which is not in the list and is stored as a glyph row. Separately, any §1 row whose archetype cell is empty is dropped here, so that glyph is never compared (see defect 11).

11. **Comparison runs in one direction only (line 438 and 444).** `for glyph in sorted(set(canon) & set(table)):` compares only shared keys. `for glyph in sorted(set(canon) - set(table)):` reports only glyphs missing from a surface. A glyph that appears in CLAUDE.md §H or on the page but not in the spec table (`set(table) - set(canon)`) is never reported. A glyph whose canonical role is blank is never compared at all.

12. **A missing HTML surface skips the glyph comparison (line 408).** `if os.path.exists(page):`. If `docs/bifrost.html` is absent, `tables` never receives the page and no problem is appended. The canonical file is checked loudly (line 403-404); this one is not.

13. **A missing CLAUDE.md skips the §H comparison (line 416).** `if os.path.exists(brief):`. Same silent skip.

14. **A non-matching Backbone bullet skips the §H comparison (line 417-418).** `m = re.search(r"- \*\*Backbone:\*\*(.*?)(?=\n- \*\*)", ...)` followed by `if m:`. If the bullet is reworded so the pattern does not match, the §H table is never built and no failure is reported.

15. **An empty sweep skips the template check (line 305).** `if canon_sweep and canon_tmpl:`. An empty string is falsy, so when every surface carries the same empty block, `check_marked` reports nothing and the "template reduces to the sweep" invariant at lines 306-311 never runs.

16. **Only the first marked block is read (line 264).** `m = mark.search(open(p, encoding="utf-8").read())`. A second `bifrost-sweep` block in the same file, with different wording, is ignored.

17. **Name shadowing (line 415 and 423).** `brief = os.path.join(ROOT, "CLAUDE.md")` is reassigned at line 423 to `brief = {}`. The code works, but the same name holds a path and then a table, which reads two ways to a maintainer.

## Notes

The sweep and glyph checks are narrow on purpose, as the comments at lines 329-334 state. The `ROLE_ALIAS` map (line 335) is the only place where two names are treated as one role; each entry is a place drift could hide.

The `LEGACY` pattern (line 53-57) is a fixed list of 1.x folder names. A new legacy folder name must be added by hand.

The heading slug (line 72-75) follows GitHub's rules as the docstring says. This review did not compare it with GitHub's output; it is read from the source only.

The check was not executed. Every finding comes from reading `tools/check-docs.py`; none was confirmed by a run against the repo.
