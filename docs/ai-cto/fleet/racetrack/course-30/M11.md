1. **"Actually sent" is checked against every `json.dumps` in the file (line 121-126).** `if isinstance(node, ast.Call) and isinstance(node.func, ast.Attribute) \` then `and node.func.attr == "dumps" and node.args \`. A `json.dumps({...})` elsewhere in `jury.py` (logging, a calibrate helper) that carries `temperature` satisfies line 163 even when the request payload does not.

2. **Sent values are collected and then discarded (line 124-126 and 163-166).** Line 126 `sent[k.value] = v` stores the AST node. Nothing reads it. Line 163 tests only `if key not in sent:`. A payload that sends `"presence_penalty": 0.5`, or a hard-coded `"temperature": 0.7`, passes. The docstring (line 23-25) says penalties are "pinned to 0 AND actually sent", which a reader takes to mean the sent value is checked.

3. **The success message overclaims (line 189-190).** `print("ok   CLAUDE.md §G sampler values match jury.py "` then `"(defaults, CLI, and the sent payload)")`. "The sent payload" is reported as matching, but only key presence was tested (defect 2). Read two ways: "match" suggests values were compared.

4. **One penalty value is copied to both penalty keys (line 65 and 91-92).** `PENALTY_CLAUSE` captures one number, and `for k in PENALTY_KEYS: vals[k] = num(hit.group(1))` assigns it to `presence_penalty` and `frequency_penalty`. If §G ever states the two separately with different numbers, the second is never read and no failure is reported.

5. **First match wins for every stated value (line 82-86).** `hit = re.search(pat, sec)`. A value restated later in §G with a different number is ignored. The same pattern applies to `temperature`, `top_p`, `top_k` and `max_tokens`.

6. **A CLI flag that is absent passes (line 168).** `if key in cli and cli[key] != want:`. If the argparse flag for a stated key is missing, or is registered in a way the walk does not see, nothing is reported. The docstring (line 26-27) says the CLI defaults are checked, and the success message says so too.

7. **A non-literal CLI default is skipped (line 135-137).** `v = _const(kw.value)` then `if v is not None:` then `cli[flag] = v`. A flag written `default=DEFAULT_TEMP` or `default=os.environ.get(...)` yields `None` and is never recorded, so it is not compared and nothing is reported.
