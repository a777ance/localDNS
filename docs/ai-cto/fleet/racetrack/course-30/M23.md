# M23 · .claude/hooks/resume.py

## Defects

- `.claude/hooks/resume.py:25` — `read_text` raises FileNotFoundError when `docs/ai-cto/checkpoint.md` is missing. The `except` at lines 36-37 then swallows it, and the hook prints nothing: no wake line, no Matrix status, no open decisions. The checkpoint is the only input that can fail, but it takes down the three outputs that do not depend on it. Fix: read the checkpoint inside its own try and print the rest regardless.
- `.claude/hooks/resume.py:19-20` — `subprocess.run(..., timeout=10)` and `return r.stdout.strip()` ignore the return code and stderr. A failing or timing-out `tools/matrix.py` call returns an empty string, or raises at line 19 when it times out. Line 31 then reads an empty status as work (see next item). Fix: check `r.returncode`, and print the error text.
- `.claude/hooks/resume.py:31-33` — `if "changed: nothing" not in status:` fires on any status that lacks that exact phrase, including the empty string that `run` returns on failure (line 20). The hook then tells the session that uncommitted work survived, when no such work was checked. The phrase is also a string match against output this file does not own; if the wording changes, every wake reports uncommitted work. Fix: parse a structured status, or check the return code before testing the phrase.
- `.claude/hooks/resume.py:26-28` — the instruction reads two ways. It says "Do not wait for the founder," then "If the founder lease in the checkpoint has expired, finish the current item, update the checkpoint, and report." One reading is "stop after the current item when the lease is expired," the other is "keep going and only report the expiry." The hook also never checks the lease itself, so it asks the model to judge a condition it has not computed. Fix: state one action for each case, and make the hook print whether the lease is expired.
- `.claude/hooks/resume.py:29` — `print(checkpoint[:3000])` cuts the checkpoint at 3000 characters with no marker. If the resume point sits after that, it is dropped without a sign that anything was missing. Fix: print the last 3000 characters, or the section headed with the resume point, and say when text was cut.

## Notes

Line 25 takes the text after the first `---`. If the checkpoint has no `---` line, the whole file is used, which is the intended fallback. If a later `---` rule appears before the resume point, nothing changes, because the split is on the first match only.

Line 18 runs `tools/matrix.py` with `sys.executable`, so the hook uses the same Python that launched it. That is correct.

The method names `observe.status` (line 30) and `decide.open` (line 35) are not checked here. They are listed in `.claude/cardinal-map.json` and `tools/matrix.py list`; verify both exist before relying on them.
