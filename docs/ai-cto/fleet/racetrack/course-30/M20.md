- .claude/hooks/decide-act.py line 109-110: "named = [f for f in new if f in text]" is a substring test, so a mention of a longer path announces a shorter scratchpad file. Line 109 also uses glob("*"), which skips dotfiles, so a dotfile in the scratchpad is never checked.

## Notes

The prose() function at line 97-99 removes fenced blocks, inline code, and any double-quoted span before the HEDGE check runs. That exemption is intended, but it means a hedge inside quotes or backticks passes, and the check cannot tell a quoted hedge from a stated one.

The docstring at line 2-19 lists ten keys. CLAUDE.md, in the Reply style section and in the hooks row of the file table, says the Stop hook enforces "the eleven reply rules". The count disagrees across files, and the eleventh rule is not in this file. The discrepancy is outside this file and was not edited.

Failing open is intended. The file allows a stop on malformed input (line 274-275), on a review exception (line 281-282), and when no transcript path is given (line 279). The docstring at line 21-23 describes the loop-safety exit. A missing transcript therefore reviews nothing and allows the stop, and that is silent by design.

The ACT rule at line 183 says to skip "an item the user has marked punt". The code never reads a punt marker, so that exemption is applied by judgment rather than by the check.

The REHEARSE hash at line 201-217 is compared against the hash that decide.rehearse writes into .claude/.matrix-rehearsed. This file does not show how that hash is computed, so whether the two agree cannot be confirmed from this file alone.

The L STEP check at line 238 treats any heading that starts with "Limits" or "Open items" as a bounce, even in ordinary prose. This is a false positive that is loud rather than silent, so it is recorded here and not as a defect.

The task file .claude/factory-tasks/M20.task names .claude/factory-tasks/M20.md as its Write target, but the orchestrator's instruction named docs/ai-cto/fleet/racetrack/course-30/M20.md. This report follows the orchestrator's instruction.
