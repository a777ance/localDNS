- tools/check-matrix.py:234 `check("cap cannot be raised", mx("observe.read", "notes.txt", MATRIX_TIMEOUT="99").returncode == 0)` cannot fail as a test of the cap. The read of notes.txt is instant, so it exits 0 whether or not MATRIX_TIMEOUT=99 would have been honored. Only the exit code is checked, not the effective cap, so the check passes even if the cap could be raised. A real test would need a slow read (MATRIX_TEST_SLEEP above the default cap) with MATRIX_TIMEOUT=99 and expect exit 124 or a clamped timeout.
