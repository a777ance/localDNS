# R1 findings: CLAUDE.md "Reply style: Briefing" rules with no gate

Source: `CLAUDE.md`, section "Reply style: Briefing" (lines 29-81).
Gates checked: `.claude/hooks/decide-act.py` (Stop hook), `.claude/hooks/cardinal.py` (PreToolUse),
`tools/check-stop-hook.py`, `tools/matrix.py`, `tools/check-matrix.py`. Scope: rules with no hook and no check.

## Findings

- `CLAUDE.md:38` **OODA structure** (Observe, Orient, Decide, Act; `Assume:` for each assumption). No gate. `decide-act.py` checks neither the four sections nor `Assume:`. The string `Assume:` appears only in `.claude/skills/orient/SKILL.md` and `.claude/output-styles/briefing.md`, and no check reads either for reply shape.
- `CLAUDE.md:40` **Orient reads from disk** (`initiatives.md`, `debt.md`, `blocked.md`; name the IDs touched). No gate. `decide-act.py` reads `blocked.md` only for the TILE check (line 225), not as an Orient step. Nothing requires the IDs to be named.
- `CLAUDE.md:50` **Tiles are only for what only the founder can decide** (DEC-010). No gate. `decide-act.py` checks that a `DECISION · DEC-NNN` tile has its three parts (line 225 onward), but nothing checks whether the question is one only the founder can decide.
- `CLAUDE.md:65` **Successes are quiet; failures are loud** (a failure opens with `FAILED:` or `BLOCKED:`, quotes the error, gives a numbered **Fix**). No gate. `decide-act.py` never checks how a failure is opened. `FAILED:` is printed by `tools/matrix.py` and `tools/racetrack.py`, but no reply check reads it.
- `CLAUDE.md:67` **No emoji; no header below `###`.** No gate. `decide-act.py` has no emoji or heading-depth check. Its only heading regex (line range near 236) matches the L-step headings, not heading depth.
- `CLAUDE.md:72` **The letter leads [hook].** Labelled [hook], but `decide-act.py` has no letter check. The only letter check is `cardinal.py` lines 114-121, which applies to the description of a Bash tool call, not to reply steps. So reply steps that start without `O · ` / `OO · ` / `D · ` / `A · ` / `L · ` pass the Stop hook.
- `CLAUDE.md:76` **Spend tokens like money; never poll, never idle** (short output, narrow reads, one slow step per call). No gate. No check measures output length, read width, or steps per call. The "never idle" half is partly covered by the NEXT ACTION branch of `decide-act.py` (near line 249), which applies only at a stop.
- `CLAUDE.md:78` **State lives on disk; ship each finished piece at once** (`docs/ai-cto/checkpoint.md` at each boundary). No gate. `checkpoint.md` is read by `.claude/hooks/resume.py` and `.claude/hooks/precompact.py`, and `tools/check-matrix.py` (line 140) checks that the precompact summary names it. No check requires it to be current at a boundary, or requires a finished piece to be shipped.
- `CLAUDE.md:80` **Stacked requests: newest first, none dropped.** No gate. No hook or check reads the order of a reply against a stack of requests. The newest-first checks in `tools/check-registers.py` and `tools/check-decisions.py` cover the INIT, DEBT and DEC registers, not replies.
