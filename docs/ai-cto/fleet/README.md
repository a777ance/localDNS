# Fleet output

Where the superfleet's lanes write. Each lane owns one folder here, named by scenario and lane
(for example `S01/L2/`), and writes nowhere else. The plan is `docs/ai-cto/superfleet.md`; the
check that a lane stayed inside its folder is `python3 tools/check-superfleet.py --review`.

Empty until a lane has run. Nothing here is a rule or a decision: it is findings and data for a
person, or for one integrating session, to act on.
