# Intent for main (draft)

Drafted 2026-11-12 by the loop, for the founder to edit and promote. The loop does not write to `main`.
Until the founder promotes this page, `main` holds no intent and this file is the draft.

## What this stack is for

A self-hosted DNS, monitoring and VPN stack on one thin client at home. It keeps the household's
network private, measures what the network carries, and produces a plain-English Network Activity
Statement that a household can read and keep.

## What it must never do

- Send private lookups to a third party. Sensitive names stay on the recursive path.
- Print a number the box did not measure. A Statement omits a figure rather than guess it.
- Put real names, figures or customer data into public git.
- Change the live box without a deploy that was diffed, backed up, validated and checked by effect.

## What done looks like

One real, measured Statement, produced by the chain from the box to a document a person keeps.
Everything before it is rehearsal. The product ratio applies: at most one loop tick in three works
on the loop itself (`docs/ai-cto/loop-tick.md`).

## Who decides what

The founder decides what goes to `main`, what runs on the live box, and every setting only a person
can change. The loop decides how a decided item is built, and records it.
