# Ten leans, forty lanes

Written 2026-11-12. Ten leans, each solved by four lanes: 40 lanes in all. The plan is a document; it holds
no instructions for any agent. The founder writes each lane's instructions from it, as in
`docs/ai-cto/superfleet.md`. Lanes write only under `docs/ai-cto/fleet/`, so no two lanes share a write area.
Each lane lands its findings on its own branch and goes through `check-superfleet.py --review`.
